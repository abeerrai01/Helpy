HOW TO USE (ZERO INSTALLATION & ZERO SETUP REQUIRED):

1. EXTRACT:
   Extract this entire ZIP archive into any folder on your computer
   (e.g., C:\Helpy, D:\Helpy, or your Desktop).

2. CREATE DESKTOP SHORTCUT (OPTIONAL BUT RECOMMENDED):
   Double-click "Setup-Desktop-Shortcut.vbs".
   This will place a "Helpy" icon and "Stop Helpy" icon right onto your Desktop!

3. LAUNCH:
   Double-click:
     - "start-helpy.vbs" (silent background launch, no black terminal window)
     OR
     - "Launch Helpy.bat" (standard launcher)
     OR
     - The "Helpy" desktop shortcut if you ran the setup above.

4. STOPPING / EXITING:
   Double-click:
     - "emergency-stop.vbs" (or "Stop Helpy.lnk" on Desktop)
     OR
     - "stop-helpy.bat"

--------------------------------------------------------------------------------
KEYBOARD SHORTCUTS & INTERACTION
--------------------------------------------------------------------------------
* Trigger / Answer Now:
  - Click the "Answer Now" button or press your configured hotkey (Ctrl + Shift + Enter).
  - Interview / Spoken answers: 2-4 concise, speakable sentences (under 60 words).
  - Coding / Scripting questions: Complete, unabridged, production-ready code.

* Scrolling During / After LLM Generation:
  - Mouse wheel: Scroll up immediately pauses auto-scroll and displays "Jump to latest".
  - Ctrl + Up / Ctrl + Down: Scroll up and down line-by-line.
  - Ctrl + Shift + Home / End: Jump immediately to Top or Bottom of the response.
  - Ctrl + Alt + Left / Right: Scroll horizontally on wide code blocks.
